# Тестовое Задание at-work

Приложение отображает список карточек пользователей с возможностью:

-   архивировать, скрывать и восстанавливать пользователей
-   редактировать данные выбранного пользователя через форму с валидацией

Реализована адаптивная верстка под десктоп и мобильные экраны.

---

## Технологии

-   **React**
-   **TypeScript**
-   **Zustand**
-   **React Hook Form + Zod**
-   **TanStack Query**
-   **SCSS**

---

## Запуск проекта

```bash
# Клонировать репозиторий
git clone https://github.com/denis290788/test-at-work

# Перейти в папку проекта
cd <имя-папки>

# Установить зависимости
npm install

# Запустить локальный сервер
npm run dev
```

После запуска проект будет доступен по адресу: http://localhost:5173
